# Arham World — Group CRM (demo)

Web CRM for **Arham World Group of Companies** — one dashboard for all 9 companies
(Signages, Displays, Digital Signages, LED, AV Systems, Technologies, Space Design, Creative Studio, Tensile).

## Run
```
npm install
npm run dev      # http://localhost:5190
```

## Modules
- **Group Dashboard** — KPIs, revenue trend, pipeline by stage, company scorecard, lead sources, follow-ups, activity, cross-sell
- **Company switcher** (top bar / sidebar chips) — filters every screen to one company
- **Leads** — capture, status, WhatsApp/call, convert to deal
- **Deals Pipeline** — drag & drop kanban; Won → auto-creates installation project
- **Quotations** — GST quote builder on each company letterhead, print/PDF, WhatsApp share
- **Customers** — shared customer master + 360° view across all companies
- **Projects & Installations** — Design → Production → Dispatch → Installation → Handover, payments
- **Service & AMC** — tickets, engineers, priority, AMC coverage
- **Tasks & Follow-ups**, **Reports**, **Team**, **Our Companies**

Demo data is generated locally and saved in the browser (user menu → *Reset demo data*).
